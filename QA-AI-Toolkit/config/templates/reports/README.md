# Reports layout

Persisted markdown reports are optional. Write to disk only when the user runs `/report`, `/feedback`, or explicitly asks to save.

## Paths

- Chat reports: `reports/Chat reports/YYYY/<english-month>/<DD>/`
- Feedback: `reports/Feedback/YYYY/<english-month>/<DD>/`

Reuse the same-day folder when it already exists. File names and content must be in English.
