# Memory — მეხსიერების ფენები

> დიზაინი: [sdlc/design/memory-and-context.md](../sdlc/design/memory-and-context.md) · გადაწყვეტილებები: [ADR-0004](../docs/decisions/0004-context-and-memory.md) (accepted) და [ADR-0005](../docs/decisions/0005-harness-v0.md) (hook-ები)
> **ავტომატიკა (Cursor, [ADR-0008](../docs/decisions/0008-cursor-support.md)):** სესიის დასაწყისში `.cursor/hooks/cursor_adapter.py` აგენტს `now.md`-ს, `PROGRESS.md`-ის მიმდინარე მდგომარეობასა და უახლეს handoff-ს „ღობეში" აწვდის, ანუ როგორც მონაცემს და არა როგორც ინსტრუქციას, და ჩატვირთვისას ინექციის მსგავს ტექსტს მონიშნავს ([ADR-0006](../docs/decisions/0006-engine-v2.md)). Cursor შეკუმშვის ზღვარს დაყენების საშუალებას არ იძლევა და შეჯამებას hook-ს არ აჩვენებს, ამიტომ შეკუმშვის შემდეგ იგივე hook აგენტს სთხოვს, მდგომარეობა სესიის ერთადერთ handoff-ში მაშინვე ჩაწეროს; გრძელ სესიაში აგენტი მას ბუნებრივ პაუზაზეც წერს.

## თვითგანვითარება — როგორ სწავლობს ძრავა

შენი ყოველი შესწორება `tasks/lessons.md`-ში ჩაიწერება და სესიის ბოლოს (`/sdlc-wrap`) კლასიფიცირდება. **მექანიკური** შეცდომა, რომლის შემოწმებაც პროგრამას შეუძლია, ავტომატურ შემოწმებად იქცევა `sdlc/checks/`-ში, რადგან წესი შეიძლება დაგვავიწყდეს, შემოწმება კი არა. **განსჯის** შეცდომა წესად იწერება. `python3 sdlc/checks/lessons_graduate.py` გაკვეთილებს აჯგუფებს. თუ ერთი და იგივე შეცდომა ორ სხვადასხვა დღეს განმეორდა, ის AGENTS.md-ში წესის დამატებას გთავაზობს, ხოლო მექანიკურ გაკვეთილს, რომელსაც შემოწმება ჯერ არ აქვს, შემოწმების აწყობას. ორივე შემთხვევაში ამტკიცებ შენ. ასე პროცედურული ფენა მხოლოდ ნამდვილი შეცდომებიდან იზრდება.

## გასუფთავება

`python3 sdlc/checks/memory_hygiene.py` ჩამოთვლის, რა უნდა გაკეთდეს: 7 დღეზე ძველი დაუარქივებელი handoff; 10+ სესიის შეჯამება, რომელიც თვის დაიჯესტად უნდა გაერთიანდეს; QMD-ის ზღვარი (არქივში 150+ ფაილი); ADR, რომლის `review_by` ვადაც გავიდა; `asterbit-debt:` ნიშანი, რომელსაც გადახედვის პირობა არ აქვს. თავად სკრიპტი არაფერს შლის და არაფერს გადაიტანს; ამას `/sdlc-wrap` აკეთებს.

## წესები

1. ეს ფაილები ჭეშმარიტების წყაროა; ნებისმიერი ძიების ან გრაფის ინდექსი მათგან აიგება. კოდის გრაფი კოდის გაჩენამდე გადადებულია (ADR-0006).
2. აქ არასდროს იწერება საიდუმლოებები, სხვისი პერსონალური მონაცემები და ვებიდან ან უცხო ფაილიდან სიტყვასიტყვით აღებული ტექსტი.
3. ყოველი ცვლილება git-ში ჩანს: `git log -p memory/` გაჩვენებს, რა როდის შეიცვალა.
