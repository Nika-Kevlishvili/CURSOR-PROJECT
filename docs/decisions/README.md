# Decisions — გადაწყვეტილებების ჟურნალი

> ყველა მნიშვნელოვანი არჩევანი (სტეკი, ხელსაწყო, მოდელი, მეხსიერება, უსაფრთხოება) იწერება ADR-ად (Architecture Decision Record — გადაწყვეტილების ჩანაწერი). თარგი: [`sdlc/templates/adr.md`](../../sdlc/templates/adr.md).

## როგორ მუშაობს

**ძველი გადაწყვეტილება არასდროს იშლება და არ გადაიწერება.** თუ აზრი შეიცვალა, იწერება ახალი ADR ველით `supersedes: NNNN`, ძველს კი სტატუსი `superseded`-ზე ეცვლება. ამიტომ ჯაჭვი ყოველთვის აჩვენებს, რა გვეგონა ადრე და რატომ შევიცვალეთ აზრი.

**ორი დრო.** front matter-ის `date` ამბობს, *როდის მივიღეთ* გადაწყვეტილება, git-ის commit-ის დრო კი — *როდის ჩავწერეთ*. ორივე ერთად დროით ისტორიას ქმნის (bi-temporal — ორდროიანი ჩანაწერი), რომლის ნახვაც ნებისმიერ დროს შეიძლება ბრძანებით `git log -p docs/decisions/`.

სტატუსები: `proposed` (შემოთავაზებული) · `accepted` (დამტკიცებული) · `superseded` (ჩანაცვლებული) · `deprecated` (მოძველებული) · `rejected` (უარყოფილი).
