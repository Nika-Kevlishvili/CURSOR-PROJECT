How to read this file
- Item format: `- [MUST|SHOULD|OPTIONAL] practice — source URL (source date) — new since 2026-10-06? yes/no`. Each item is one physical line.
- Strength follows the source's own wording: must, never, always, required = MUST; should, recommend, prefer = SHOULD; can, optional, consider = OPTIONAL. "(strength inferred)" means the source used no such word and SHOULD is my choice.
- `yes` only when the source is dated 2026-10-06 or later, or the feature first ships in Claude Code v2.1.291 to v2.1.293. Everything else is `no`, including v2.1.290 (2026-10-05) and Mods (v2.1.287, 2026-10-01). Docs pages carry no revision date, so `no` on them means not provably new, not unchanged. Inside each section the `yes` items come first.
- Dates: `(docs, undated)` is an undated docs page fetched 2026-10-07; `(v2.1.292, 2026-10-06)` is a changelog entry; any other date is a publication date.
- `(Claude API, not a Claude Code setting)` marks API-only features. `UNVERIFIED` marks a claim I could not confirm in the page text itself; "page extract" marks a fact I saw only in the fetch tool's summary of a page, never in its raw text.
