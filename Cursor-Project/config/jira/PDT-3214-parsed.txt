For Liabilities (from LPF) and Receivables generated from EasyPay payments, the system should follow the same accounting period rules as for all other payments.
If the payment date falls within a previous accounting period and that period is still open, the Liability/Receivable should be created in that accounting period. If the accounting period is closed, the Liability/Receivable should be created in the next currently open accounting period.
