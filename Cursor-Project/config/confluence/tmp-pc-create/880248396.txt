Create Product Contract
As a system user
I want to be able to create a contract for a product
So that I have possibility to effectively manage the automated processes, tasks and customer communication

Acceptance criteria
Creating a contract for a product is possible from Product Contract's listing page by clicking on a 'Plus' button

e.g. product 1 has added related product 2. To create contract with product 1 system should check if customer already have contract with product 2

Product contains related product/service with ‘Obligatory condition' selected and 'Activated contract’ 
System should check if customer has already concluded a contract with related product and contract is Active in terms or Active in Perpetuity; if not display an error and doesn’t create new contract

e.g. product 1 has added related product 2. To create contract with product 1 system should check if customer already has active contract with product 2

Product contains related product/service with ‘At least one' condition selected and 'Concluded contract’ 
Signed (signed by customer, signed by both sides, special processes), entered into force, active in terms, active in perpetuity - should be checked

System should check if customer has already concluded a contract to at least one of related products; if not display an error and doesn’t create new contract

e.g. If Product 1 has 10 related products from where 5 is marked to 'Obligatory condition' and 5 has selected 'at least one condition' customer should have concluded 6 contracts to related products (5 for the five products with “Obligatory condition” and 1 for any of the other five products with “at least one condition”) and only in this case will be able to conclude a contract with this product

Product contains related product/service with ‘At least one' condition selected and 'Activated contract’ 
System should check if customer has already activated contract to at least one of related products; if not display an error and doesn’t create new contract  (contract with Active in terms or Active in Perpetuity statuses)

If in the product only SLP is selected in the metering type of the point of delivery, it means that it is possible to add only those PODs to the contract which has the nomenclature value selected from the measurement type nomenclature and it is different from By settlement periods options.

If both options are selected in the product (By settlement period and SLP), it means that it is possible to add all the PODs to the product contract.
