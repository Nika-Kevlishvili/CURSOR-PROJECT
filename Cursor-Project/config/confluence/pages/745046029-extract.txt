 User story 1 As a customer of Energo-Pro Sales or Energo-Pro Energy services, I want to be able to get contract document for the product of my choice, So that I can check, validate and easily sign it on my device Business Flow Fit (Trigger & Outcome) The portals will send the POST-request with the specified parameters. Phoenix will have to find the correct template to use. To do so, Phoenix will check the selected Product version and from the attached templates select the one, starting with the string &ldquo;CSP&rdquo;. If there are none return null, if there is more than 1 return error, else, Return the generated pdf, according to the Phoenix-Template. Request Parameters Request Type: POST Endpoint: /contract/template {Product_ID, Product_Version, ContractJSON} The Sales Portal will send the contract JSON with the same structure as in Phoenix Response Parameters The generated file named according to the settings in the Phoenix template object.
