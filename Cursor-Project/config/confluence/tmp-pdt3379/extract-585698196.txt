 User Story As a system user I want to be able to create Disconnection of the power supply object So that I will be able to manage POD disconnection process in a flexible and correct way Design: Disconnection_Of_The_Power_Supply (adobe.com) New design: https://www.figma.com/design/rdEFquUpErpUGFXdQt7vmV/Energo-Pro?node-id=5412-1463 Acceptance criteria: Creating a Disconnection of the power supply is possible from its listing page by clicking on a 'Plus' button A Disconnection of the power supply object with all required information can also be created via EMEP. Manual creation from the listing page remains available (same create flow as today).(1) Clicking on a Plus button will open Disconnection of the power supply's creation page Check system user permissions to be able to create a new Disconnection of the power supply For creating such object, user should have any of the permissions listed here: Create Disconnection of the power supply as a Draft Allows to create object only as a draft and do not start process Create Disconnection of the power supply as Execute Allows to create object and it is possible to start process for tax cancellation and generation Enable Plus button when user has one of the permissions Disabled Plus button when user does not have any of the mentioned permissions Default state of the Disconnection of the power supply object contains fields: Number Mandatory Always disabled Empty on creation page Text field After creating an object, system should display its number with the following logic: Disconnection-ID of newly created object (for example, Disconnection-56) In the given example, Disconnection is hardcoded prefix for number and 56 is ID of an object Date Mandatory Always disabled Date picker Format: DD.MM.YYYY By default, should set current day of the creation Status Mandatory Always disabled Empty on creation page Two hardcoded values: Draft Executed System should automatically set a value according to the status of the object If it is as a draft should set Draft If it is saved and executed should be set Executed Import button Enabled for Executed objects. Disabled for Drafts.
