=== EXCERPT ===
 User Story As a system user I want to be able to create and manage nomenclature for ‘Taxes for the grid operator’ So that I will have a possibility to change values without system deployment Design: Nomenclatures_Bundle_final (adobe.com) Acceptance Criteria Check permission to see the nomenclature for 'Taxes for the grid operator' The nomenclature name should be 'Taxes for the grid operator' Not to be able to edit/delete nomenclature name Selecting 'Taxes for the grid operator' in the nomenclature dropdown will do the following: In right panel list of nomenclature items will be loaded: Name is displayed in the list Blue color for active items Red color for inactive items Deleted items are not displayed 'Plus' button is active if user has permission 'Create Taxes for the grid operator nomenclature' if no use disabled state (gray color) ‘A-Z' button is active if user has permission ‘Edit Taxes for the grid operator nomenclature' if no use disabled state (gray color) 'A (Move to top)' icon is active if user has permission 'Edit Taxes for the grid operator nomenclature' if no use disabled state (gray color) ‘Remove' icon is active if user has permission 'Edit Taxes for the grid operator nomenclature’ if no use disabled state (gray color) Pagination will always appear Number of records dropdowns will have hardcoded values: 25, 50, 100 25 is selected by default Search box will appear in footer It is possible to search by Type of disconnection, Grid operator or Supplier type By default search icon is gray and becomes active after typing 1 symbol in search box Clicking on ‘Search’ Icon will run search 'X' button next to search icon will clear search results and will empty the search field Changing the nomenclature will empty the search field Scroll/Pagination Footer is always fixed to bottom, so Search box, number of records and pagination is not hidden on scrolling To be able to type page number and after clicking on Enter or leave the field will directly load that page. If page number is not valid or does not exist the field should be cleared after clicking on Enter or leave the field ‘Plus’ button/'A-Z' icon is displayed in each page and page is scrollable Update order of added nomenclature items: Sort order will be used for displaying items in dropdowns in system Newly added item will always be added as last item Clicking on ‘A-Z’ icon will reorder all items alphabetically.
