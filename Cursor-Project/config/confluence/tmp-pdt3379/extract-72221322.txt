 User Story As a system user I want to be able to update Request for disconnection of the power supply's data So that I will have possibility to correct my mistake Design: Request for disconnection of the power supply (adobe.com) Acceptance criteria: Check system user permissions to see edit icon on Request for disconnection of the power supply's listing/detail page. If no such permission, edit icon will be disabled Edit Draft Request for disconnection of the power supply Allows to edit all Request for disconnection of the power supplies' objects with status Draft It is possible to edit only Draft object and Executed. objects with the status Fee charged should be locked and it is not possible to edit Clicking on an edit icon on listing/detail page will allow edit mode All fields are editable with the regular flow for Draft object List of PODs should be updated when object is with status Draft and is opened in Edit mode. If for POD all overdue liabilities are payed the POD should be removed from the list. PODs listed on the second tab (POD tab) are filtered according to the Supplier type selected on the request header and the customer from the linked Reminder for disconnection: If Supplier type is Current, only PODs that are active on the current date in the contract of the customer (customer ID) included in the reminder are listed. If Supplier type is Previous, only PODs that are not active on the current date in the contract of that customer (from the reminder) are listed. This filter applies when the POD tab is loaded or refreshed (including after changing Supplier type, Grid operator, or Reminder for disconnection on tab 1).
