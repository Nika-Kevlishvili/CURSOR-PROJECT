 User requirement As a system user, I want to create an “charge fee” invoice for each selected liabilities in the request for disconnection So that I will always possible to generate “Charge fee” invoice Short description about “Charge fee” invoice generating process When a customer does not cover their liability before the due date, the system first issues a notification through the “Reminder for Disconnection” object to inform the customer about the outstanding liability. If, even after this reminder, the liability remains unpaid, the system user can create a “Request for Disconnection” to inform the grid operator to disconnect the customer’s points of delivery. (The Request for Disconnection takes its list of customers from the Reminder for Disconnection.) Change description Current flow After sending a Request for Disconnection, if the liability is still not covered by the due date, the system user has the option to charge the customer an additional late fee. Once the Request for Disconnection is executed, a “Charge Fee” button becomes available. By clicking this button, the system generates an individual Charge Fee invoice for the selected customer. This invoice is generated based on the customer’s liabilities, but currently it is only created for liabilities that already have an outgoing document. Expected flow By this change for any type liabilities which are selected in the request for disconnection should be generated “Charge fee” invoice. This liabilities: Liability - generated by invoice (Product contract) (Already work) Manual liability - generated manually (with billing group) LPF - for LPF which is generated by invoice/For LPF liability which is generated by manual liability Rescheduling This change should be implemented in Request for disconnection/Disconnection of the power supply - Charge fee logic. Reconnection of the power supply - Express reconnection Rescheduling liability. If a rescheduled liability is selected in the “Request for Disconnection,” then after clicking the “Charge Fee” button, the generated invoice should include this data Customer - should be taken from liability Billing group -take billing group from rescheduling object(if rescheduling includes only one billing group), also rescheduling can include several number of billing group, In this case, the system should take the billing group from the contract with the highest ID.
