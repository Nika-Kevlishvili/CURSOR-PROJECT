რეგრესიის ტესტ ქეისები სკოუპის მიხედვით

396 ტესტ ქეისი REG ბორდიდან. დამოუკიდებელი სკოუპი ჩავარდნის შედეგით დგინდება. ბორდის ვერსია მხოლოდ შედარებისთვისაა: Version 1 = HIGHEST, Version 1.1 = HIGH, Version 1.2 = MEDIUM.

წყარო: 2026 წლის 29 სექტემბრის ექსელი. კლასიფიკაცია სათაურით მოხდა. ნაბიჯები ცალ-ცალკე არ წაკითხულა.

უმაღლესი სკოუპი

აქ მხოლოდ ის ქეისებია, რომლებსაც უმაღლესად ვაფასებ. ჩავარდნა ცვლის დარიცხულ თანხას, ან იმას, ვის ერიცხება და ვის აქვს მიწოდება. ბორდის Version 1 ამ სიას არ არჩევს.
